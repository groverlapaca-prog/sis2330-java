#Semana 01: Git y GitHub
## Objetivo
Aprender el control de versiones utilizando Git y Github 
## Actividades 
- Instalacion de Git.
- Configuracion del usuario.
- Inicializacion del repositorio.
- Creacion del archivo .gitignore.
- Creacion del README.
- Publicacion en GitHub.
## Comandos principales 
- git init 
- git status 
- git add
- git commit 
- git push
