# Calculadora Haskell

## Descripción
Proyecto de calculadora realizado en Haskell
utilizando Stack.

## Como correr

Para compilar:
stack build

Para ejecutar:
stack run

## Modulos

- Lib.hs: contiene las funciones puras suma,
  doble y promedio.
- Main.hs: permite ingresar dos numeros
  y mostrar su suma.

## Funcionamiento
El programa solicita dos numeros al usuario
y muestra el resultado de la suma.
