SIS2330 - SEMANA 2: SISTEMA DE CALIFICACIONES

Archivo principal: SistemaCalificaciones.java

Requisitos:
- Registra 5 estudiantes y 3 notas por estudiante.
- Usa un arreglo bidimensional double[5][3].
- Calcula promedio, nota máxima, nota mínima y estado.
- Aprueba con promedio mayor o igual a 51.
- Valida notas entre 0 y 100.
- Captura InputMismatchException cuando se escribe texto en lugar de un número.
- Utiliza métodos static y una sola clase.

Para compilar:
    javac SistemaCalificaciones.java

Para ejecutar:
    java SistemaCalificaciones

Nota: el programa lee nombres de una sola palabra con Scanner.next().
